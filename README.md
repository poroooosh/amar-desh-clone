# 📰 Amar Desh Clone

A simple and responsive **Bangladeshi news website clone** inspired by *Amar Desh*.  
Built with **HTML**, **CSS**, and a bit of **Font Awesome** for icons.

---

## 🌐 Live Demo

👉 **[Click here to view the live demo](https://poroooosh.github.io/amar-desh-clone/)**

---

## 📋 Project Overview

This project recreates the layout and design of the *Amar Desh* newspaper website using only front-end technologies.  
It focuses on clean structure, responsive design, and proper alignment of footer, header, and main content areas.

---

## 🧩 Features

- 📰 Fully responsive layout  
- 🔗 Clean header and footer sections  
- 🎨 Hover effects with red underline  
- 🕓 Auto-updating date and time display  
- 🌍 Social media icons (Instagram, Twitter, YouTube)  
- ⚙️ Organized footer with contact and publication info  

---

## 🧱 Technologies Used

| Technology | Purpose |
|-------------|----------|
| **HTML5** | Structure and content |
| **CSS3** | Styling and layout |
| **Font Awesome** | Icons for social links |
| **Unicode Bangla Font** | Clean typography |
